# Saanjh 0.5 — Calm UI, cloud-auth foundation

- Redesigned warm ivory/sage interface: calmer reading hierarchy, editorial serif titles, softer guidance cards, accessible focus states, responsive mobile navigation drawer, improved welcome experience and message composer.
- Google account button with a real OAuth route ready for Supabase configuration. Not a fake local login.
- Optional cloud family state, optimistic revision conflict detection, manual JSON export, personal data deletion, session-aware Gemini endpoint and 20-reply server-side prototype usage policy.
- Distinguishes local-browser-only from remotely synced data. Existing local history is **not automatically uploaded**: after first Google login user chooses fresh start or import explicitly.
- Maintains all v0.4 features: Gita original Sanskrit, Hindi/English source translation, separate meaning and application, another approach, multiple conversations, memory, separate children and faith experiences.
- Still local-only, and not ready for real child data or public deployment without authentication rollout, security/privacy review, and AI quality assurance.
